# 📄 DocScan Studio Pro

**DocScan Studio Pro** is a high-performance desktop web application built for laptop and desktop computers. It converts images, multi-page PDFs, and scanned documents into professional-grade PDF and multi-format files. 

Featuring signature **Magic Color Background Whitening**, an **8-Point Manual Crop Studio** with Magnifier Loupe lens, **Perspective Keystone Correction**, and **Tesseract OCR**, DocScan Studio Pro delivers a complete document scanning workflow directly inside your web browser.

---

## 🌟 Key Features

### 1. 🔲 8-Point Manual Crop & Perspective Correction
- **8 Prominent Interactive Handles**:
  - **4 Corner Pins** (Cyan `#00d2ff`): Precision vertex placement.
  - **4 Edge Midpoint Pins** (Gold `#ffd600`): Dragging an edge midpoint pin translates the entire side smoothly.
- **Magnifier Loupe Lens**: Floating 3.0x magnification lens overlay active on all 8 handles for pixel-perfect edge alignment.
- **Auto-Align Edge Detection**: Automatic quadrilateral boundary detection using Sobel gradient magnitude scanning.
- **Perspective Keystone Correction**: One-click **"Perspective Fix"** button levels trapezoid documents (where the top/head is farther away and bottom is closer) into squared 90-degree page bounds.

### 2. 🪄 CamScanner Magic Color & Whitening Filters
- **Local Background Matrix Division**: Normalizes paper illuminance across $32 \times 32$ cell matrices, completely eliminating paper shadows, yellow flash tint, and ambient room lighting falloff.
- **Pure White Paper Mapping**: Automatically maps paper background pixels to pure crisp white (`#FFFFFF`) while deepening black and colored text ink (blue pen, red stamps).
- **Presets**: Magic Color, Clean B&W Scan, Grayscale, De-shadow, and Original.
- **Fine-Tuning Controls**: Sliders for Brightness, Contrast, Saturation, and Sharpness.
- **Batch Whitening**: Apply your chosen filter preset to all pages in one click.

### 3. 📂 Multi-Page Document Organizer
- Left sidebar thumbnail tray showing page numbers and active filter badges.
- Re-order pages via drag-and-drop or move up/down buttons.
- Page rotation (90° steps), page duplication, individual deletion, and **1-Click "Clear All"** workspace reset.

### 4. 📄 Multi-Format & PDF Export Engine
- **PDF Export Capabilities**:
  - Page Sizes: **A4**, **US Letter**, **US Legal**, and **Auto-Fit** (fit PDF size to exact image aspect ratio).
  - Page Orientations: Auto Detect, Portrait, Landscape.
  - **Compression Quality**: Adjustable slider from **10% (compact)** up to **100% (maximum clarity)**.
  - **Searchable PDF (OCR Layer)**: Embedded selectable text layer generated by Tesseract.js.
  - Document Title & Author Metadata customization.
- **Alternative Export Formats**: PNG, JPEG, and TXT plain text extractions.

### 5. ⚡ Real-Time Progress & 120 FPS Performance
- **Zero-Lag Handles**: Handle dragging runs at an instant 120 FPS on local canvas state without blocking main-thread filtering.
- **Instant Preset Switch**: Live preview scales dynamically (~15ms filter execution) for instant 0ms UI feedback when clicking preset cards.
- **Progress Status Banner**: Animated percentage status bar (`0%` to `100%`) for PDF rendering, batch whitening, and export routines.

## 🚀 How to Launch & Run

### Method A: 1-Click Launcher (Recommended)
1. Open the project folder `D:\CamScanner`.
2. Double-click **`Start-DocScan-Studio.bat`**.
3. Your web browser will automatically open to **`http://localhost:5173/`**.

> 💡 *Tip: Right-click `Start-DocScan-Studio.bat` → **Send to → Desktop (create shortcut)** to place a 1-click icon right on your Desktop!*

### Method B: Terminal Command
1. Open Command Prompt or PowerShell.
2. Navigate to the project directory:
   ```cmd
   cd D:\CamScanner
   ```
3. Run the development server:
   ```cmd
   npm run dev
   ```
4. Open your browser and navigate to **[http://localhost:5173/](http://localhost:5173/)**.

---

## 🛑 How to Stop / Close the Application

1. **Closing Browser Tab**: Closes the visual interface.
2. **Stopping the Server**: Close the black Command Prompt terminal window (or press `Ctrl + C` inside it).
3. **Computer Shutdown**: Turning off or restarting your PC automatically closes the system.

## 🌐 How to Share with Friends

### 1. Local Wi-Fi Sharing (No Install Needed for Friend)
1. Run `npm run dev -- --host` on your laptop.
2. The terminal will display your Network IP (e.g., `http://192.168.1.15:5173/`).
3. Share that Network URL with anyone on the same Wi-Fi network. They can open it on their laptop or mobile phone instantly!

### 2. Copying to Another Computer
1. Copy the `CamScanner` folder onto a USB Flash Drive or Google Drive.
2. Ensure [Node.js](https://nodejs.org/) is installed on the target computer.
3. Open Command Prompt inside the folder and run:
   ```cmd
   npm install
   npm run dev
   ```

### 3. Free Online Hosting (Vercel / Netlify)
Upload the project repository to **Vercel** ([vercel.com](https://vercel.com)) or **Netlify** ([netlify.com](https://netlify.com)) for a permanent, free online link (e.g., `https://my-docscan-studio.vercel.app/`).
